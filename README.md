# SEO Content Brief Automation Tool

An AI-powered web application that generates complete, 
research-backed SEO content briefs from a single keyword 
input — powered by the Claude API with live web search.

## What It Does

1. You enter a target keyword, industry, content goal, and type
2. The tool searches the web for current competitor content
3. Claude AI generates a complete SEO content brief including:
   - Research summary and competitive landscape
   - Search intent analysis
   - Target audience profile
   - Recommended title / H1
   - Meta description (under 160 characters)
   - H2 structure with content notes for each section
   - Unique content angle
   - Internal link suggestions
   - Estimated word count with reasoning

## Why It's Different

Unlike generic SEO tools, this generator searches the web 
before writing — analyzing what competitors are actually 
ranking for and identifying gaps a new piece of content 
could fill. Every brief is grounded in real-time research,
not static templates.

## Tech Stack

- HTML / CSS / JavaScript
- Claude API (claude-sonnet-4-5)
- Anthropic Web Search Tool
- Live Server (local development)

## Results

- Generates a complete SEO brief in under 2 minutes
- vs. 2–3 hours of manual keyword and competitor research
- Validated across 10 target keywords in 3 industries
- Includes competitive analysis, content angle, and word count

## How to Run

1. Clone or download this repository
2. Open the folder in VS Code
3. Right-click index.html and select Open with Live Server
4. Enter your Claude API key in the app
5. Fill in your keyword details and click Generate SEO Brief

## Example Output

Input: "PlayStation 5" — Gaming industry

Output includes:
- Competitive landscape (GamesRadar, TechRadar, GameSpot)
- Mixed informational and commercial search intent
- Target audience: 20s-40s researching $400-700 purchase
- Recommended title with 2026 freshness signal
- 6 H2 subheadings with content notes
- 3,500-4,500 word count recommendation with reasoning
